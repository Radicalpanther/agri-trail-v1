# AgriTrails

AgriTrails is an agritourism platform designed to connect travelers with authentic farm stays, harvest experiences, and seasonal agricultural traditions across India.

## Features

- **Curated Farmstays**: Explore farmstays across Himachal Pradesh, Karnataka, Kerala, Maharashtra, Punjab, Uttarakhand, and more.
- **Hands-on Agri Experiences**: Book seasonal activities like apple harvesting, coffee plantation walks, organic jaggery making, spice trails, and paddy transplanting.
- **Farm Fresh Marketplace**: Add authentic farm produce (organic jaggery, Ratnagiri Alphonso, wildflower honey) directly to bookings.
- **Farmer Portal**: Host dashboard to manage listings, seasonal bookings, guest capacity, and harvest schedules.
- **Responsive Design**: Fast, lightweight responsive interface with interactive booking modals and search filters.

## Tech Stack

- **Frontend**: HTML5, Modern CSS3 with custom variables, Vanilla JavaScript
- **Backend / Dev Server**: Node.js & Express
- **Assets**: Optimized web assets and local media storage

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
